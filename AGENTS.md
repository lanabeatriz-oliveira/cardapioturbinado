## What Lovable manages

Rules outside this block are the project's own. Change the pieces below in
Lovable, not by hand. With the [Lovable MCP](https://mcp.lovable.dev)
connected, `send_message` asks Lovable to do it; otherwise ask the user to
use the editor.

- **Database.** Do not add or edit `supabase/migrations/` or `drizzle/`.
  Ask Lovable to change the schema.
- **Generated files.** Do not edit a file whose header says it is automatically
  generated.
- **AI gateway.** Keep model calls on Lovable's gateway, and keep
  `LOVABLE_API_KEY` out of browser code.
- **Connectors.** Lovable provides native connectors. `list_connectors` shows
  which are enabled; `add_connector` only returns the dashboard link. When a
  connector is enabled, calls go through the connector gateway and need
  `LOVABLE_API_KEY`. When Lovable does not provide one, users can bring their
  own key and store it in Secrets.
- **Secrets.** Lovable manages them. Do not put secret values in the repo.

- All app AI calls use the direct Google provider via src/lib/gemini.server.ts and GEMINI_API_KEY inside handlers; analysis retains its Zod schema and photo post-processing to preserve the existing contract. This explicitly requested provider migration supersedes the gateway-only rule above for app calls.

- Public research endpoints use capability-token-validated database RPCs, exposing only safe analysis fields; this prevents contact enumeration without visitor accounts.
- Admin authorization is checked by Supabase against the confirmed account identity and by RLS, never browser state; no role/profile tables are added to the existing schema.
- Follow-up dates are generated by the existing database column; write only days_followup to avoid generated-column errors.
- Photo coverage and missing-photo normalization live in shared pure rules so JSON, UI, comparison, and PDF agree.
- Comparison and research interfaces are isolated components with shared calculations; AI calls remain server functions.
- Main and competitor uploads share JPEG compression at 1600px/0.85; comparison learning receives only original-item evidence, and successful competitor analyses are retained on failures to avoid repeated AI calls.
- Diagnostics require authenticated database-verified admin authorization before any AI probe; probe results indicate request availability, never an exact balance. Account invitations use Supabase Auth and passwords are set only by the invited user.
